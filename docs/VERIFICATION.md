# Build pass 1 verification

## Executed

- TypeScript production build succeeds. Standalone static output in `dist/`.
- 18 Vitest tests pass: five-second history and immutable snapshots, replay timing and damage, cooldown/two-Echo cap, three weapons, piercing, armor/invulnerability, defeat/restart, all upgrades and arena progression, boss phases/victory, threats from all seven enemy types including boss, wave duration, valid/corrupt/blocked saves, swept projectile hits at 20 FPS, summoner cleanup, passive-play defeat, and exclusion of redundant cooldown ranks.
- Mobile Chromium: tutorial, keyboard movement, Echo, pause with frozen simulation, sound setting, defeat, save/unlocks, restart, all chapter transitions, boss victory and two simultaneous real touch pointers pass.
- Mobile WebKit: tutorial, input, Echo, pause, settings, defeat/restart, saved unlocks, upgrades, arenas and victory pass. Fixed-duration waits were replaced with state-based waits for slower software rendering. The CDP multitouch test is Chromium-specific and intentionally skipped here.
- Desktop Chromium: the same screen flows pass. The mobile-only CDP multitouch test is intentionally skipped.
- Final portrait layout uses the full viewport for menus/HUD/controls and centers the undistorted arena. Production smoke and the real multitouch test passed again after this layout change.
- Final browser suite: 7 passed, 2 intentional CDP skips. WebKit was run with locally extracted Debian libraries because this container lacks root access for the normal dependency installer; its bundled runtime was launched successfully. Physical iPhone Safari is not implied by WebKit emulation.
- Production smoke: no development test bridge, tutorial through live combat, touch pause, defeat/menu return, 320×568 settings access, no horizontal overflow and no JavaScript errors.
- Visual inspection: production menu, live portrait combat, controls and Echo, victory screen. Production screenshots are in `docs/screenshots/`. Additional screenshots are generated by the browser tests in ignored `test-results/`.
